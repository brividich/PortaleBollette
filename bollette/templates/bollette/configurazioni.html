📡 Endpoint Webhook Cloud per Home Assistant

Configura questa automazione in Home Assistant per inviare dati al Portale e ricevere i prezzi.
URL ENDPOINT ASSEGNATO: {{ webhook_url }}
Codice Automazione HA pronto (automations.yaml): 
automation:
  - alias: "Sincronizza Portale Bollette"
    trigger:
      - platform: time_pattern
        hours: "/1"  # Ogni ora
    action:
      - service: rest_command.send_to_portale_bollette
        data: {}

# In configuration.yaml:
rest_command:
  send_to_portale_bollette:
    url: "{{ webhook_url }}"
    method: POST
    content_type: "application/json"
    payload: >-
      {
        "temperatura_interna": {% templatetag openvariable %} states('sensor.temperatura_salone') {% templatetag closevariable %},
        "caldaia_accesa": {% templatetag openvariable %} is_state('binary_sensor.stato_caldaia', 'on') {% templatetag closevariable %}
      }
